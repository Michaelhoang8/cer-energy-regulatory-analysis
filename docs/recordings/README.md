# Recorded report review

[Watch or download the walkthrough](walkthrough.mp4)

Continuous automated browser recording of the working report using official CER and NRCan data. It demonstrates reporting-point selection, monthly denominators, incident-map filtering, and quality review. This is not manual development footage, a native Power BI recording, or evidence of government employment.

The [capture manifest](capture_manifest.json) records the source snapshot, checks and SHA-256 hashes.
